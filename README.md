# Kubra Bozan | Data Portfolio

Source for my portfolio home page, hosted on GitHub Pages.

## Publish (one-time)
1. On GitHub, create a **public** repo named exactly `kubrabozan.github.io`.
2. Links already point to `kubrabozan` (GitHub) and `linkedin.com/in/kubrabozan`. If either username changes, search and replace it in both folders.
3. Push this folder to that repo. It goes live at `https://kubrabozan.github.io` in about a minute.
4. Create a repo `ab-testing-marketing-campaign`, push it, then go to **Settings → Pages → Deploy from branch → `main` / `docs`**.
   The case study goes live at `https://kubrabozan.github.io/ab-testing-marketing-campaign/`.

## Add a project
Add one object to the `PROJECTS` array in `index.html` and drop a thumbnail into `assets/`.
